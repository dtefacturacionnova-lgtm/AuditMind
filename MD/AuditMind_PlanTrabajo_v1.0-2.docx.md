# **GUIA DE PROMPTS DE ALTO IMPACTO**

Estos son los principios para escribir prompts que generen codigo de calidad production-grade con Claude y Gemini. La diferencia entre un prompt mediocre y uno excelente puede ser horas de debugging.

## **Anatomia del Prompt Perfecto para Claude Code**

| 1\.  ROL \+ CONTEXTO "Eres un arquitecto de software senior especializado en sistemas SaaS enterprise multi-tenant con NestJS y PostgreSQL." 2\.  DESCRIPCION DEL SISTEMA (no asumas que Claude recuerda) "El sistema se llama AuditMind. Es un SaaS de auditoria con monorepo Turborepo: apps/api (NestJS), apps/web (Next.js 15). Base de datos: Supabase PostgreSQL con Prisma ORM. Multi-tenant con RLS." 3\.  TAREA ESPECIFICA Y COMPLETA (no partes pequeñas) "Implementa el modulo completo de X con estos metodos exactos: \[lista\]. Cada metodo debe: \[comportamiento exacto\]." 4\.  RESTRICCIONES TECNICAS "TypeScript estricto. Sin any. Usa Prisma para acceso a datos. Lanza HttpException con mensajes descriptivos. No uses librerías externas que no esten en el package.json." 5\.  FORMATO DE RESPUESTA "Muestra el codigo completo de cada archivo. Incluye los imports. No omitas partes con comentarios como // resto del codigo." |
| :---- |

## **Los 5 Prompts de Recuperacion — Cuando Algo Sale Mal**

| Situacion | Prompt de Recuperacion |
| :---- | :---- |
| El codigo de Claude no compila | Tengo este error de TypeScript: \[pega el error\]. El archivo afectado es \[nombre\]. El contexto del sistema es \[descripcion breve\]. Dame el codigo corregido completo del archivo, no solo el fragmento. |
| Gemini genero codigo que no sigue el patron del proyecto | El codigo que generaste no sigue los patrones del proyecto. En nuestro sistema usamos \[patron especifico\]. Reescribe el componente/servicio siguiendo exactamente ese patron. |
| Hay un bug de logica que no encuentras | Tengo un bug: \[descripcion del comportamiento\]. El codigo relevante es \[pega el codigo\]. Analiza paso a paso que esta pasando y dame la correccion con explicacion de la causa raiz. |
| Claude se quedo sin contexto a mitad de una tarea | Continuemos la tarea anterior. El sistema es AuditMind \[descripcion\]. Ya tenemos implementado \[lo que funciona\]. Necesito que completes \[lo que falta\]. Aqui esta lo que tenemos hasta ahora: \[pega el codigo\]. |
| El seed no genera datos correctos o hay errores de Prisma | Tengo este error de Prisma: \[error\]. El schema relevante es \[pega el modelo de Prisma\]. El codigo que falla es \[pega el codigo\]. Corrige considerando las relaciones del schema. |
